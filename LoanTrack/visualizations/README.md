# 📊 Output Visualizations & Charts

This directory contains evaluation charts (`.png` files) generated automatically when running `python train.py` or `python cli.py train`.

- `accuracy_comparison.png`: Comparison bar charts for all 13 algorithms
- `roc_curves.png`: Receiver Operating Characteristic curves & AUC scores
- `confusion_matrix.png`: Confusion matrix heatmap for the best model

> **Note**: This folder contains generated images, NOT Python source code. Plot generation code is located in `src/loan_ml/plotting/`.
